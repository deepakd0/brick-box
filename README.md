# Brick Box 12-in-1

An original LCD brick-game handheld in the browser, with 12 games, speed 1-10 and level 1-10.

- Play: https://deepakd0.github.io/brick-box/
- Laptop (keyboard): `laptop.html`. Phone (touch, installable, offline): `phone.html`

Games: Block Drop, Odd Blocks, Rising Floor, Lane Racer, Tank Duel, Snake, Frog Hop, Brick Breaker, Row Blaster, Gap Filler, Copy Cat, Drop & Shoot.

Keys: arrows move, Space/X rotate or fire, Enter start/pause, M sound, R reset, O on/off.
In the menu: Left/Right pick a game, Up speed, Down level, Fire to start.

Test: `node tests/smoke.mjs`
